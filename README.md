# FinTrust Digital Bank Experience Lab Project — Data Analytics Track

## AnalystLab Africa Internship Programme

This repository documents my work on the **Data Analytics track** of the FinTrust Digital Bank Experience Lab Project — a 4-week simulated internship project focused on turning synthetic customer and transaction data into actionable business intelligence for a fictional digital bank, FinTrust.

> **Disclaimer:** FinTrust is a fictional organisation. All customers, transactions, and financial data used in this project are synthetic and created for educational purposes only (AnalystLab Africa).

## Project Overview

FinTrust Digital Bank has customer and transaction data but lacks an integrated solution to provide visibility into behaviour, flag risk-related patterns, and support data-driven decision-making. My role on the Data Analytics track is to turn this raw data into KPIs, dashboards, and business insights.

## Week 1 — Foundation & Planning

Week 1 focused on understanding the business problem and data before any development work. Deliverables:

- Business Understanding (problem, importance, track contribution)
- Resource Review (Customer Data, Transaction Data, Data Dictionary)
- Track Objectives & Success Criteria
- Data Understanding & Profiling Report
- 8 Analytical Questions
- 5-KPI Definition Table
- Dashboard Wireframe
- Initial Plan for Weeks 2–4
